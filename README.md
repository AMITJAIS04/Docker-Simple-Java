# Docker Simple Java

This is a simple Java project created to understand the basic Docker workflow.

## Project Overview

In this project, I:

1. Created a simple Java program.
2. Created a `Dockerfile` to containerize the Java application.
3. Built the Dockerfile to create a Docker image.
4. Created and ran a Docker container using the image.
5. The application displays the current date and time in the terminal.

## Docker Workflow

```text
Java Application
       ↓
   Dockerfile
       ↓
   Docker Image
       ↓
 Docker Container
       ↓
